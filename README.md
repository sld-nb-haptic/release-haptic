# AUTD3 Verified by SLD  
本リポジトリは、東京大学発の超音波触覚デバイス「AUTD3」オープンソースをベースに、  
SLD（新光商事エルエスアイデザインセンター）が動作検証した環境・コード・設定をまとめたものです。

東京大学 篠田・牧野研究室の公式リポジトリを基に、  
SLD 内での実機動作確認に必要な手順・スクリプト等を整理・公開しています。


## 背景 / Overview
- AUTD3 は、空中超音波による非接触触覚デバイスです。  
- 東京大学のオープンソースとして公開されているコード・回路・ドライバをベースにしています。  
- 本リポジトリでは **SLD 内での動作検証結果** を反映し、  
  実際に動作する環境構築手順やサンプルコードを提供します。  


## 本リポジトリの目的
- AUTD3の導入・検証のハードルを下げる
- 実機動作に基づく再現性のある環境構築情報を提供する
- FPGA／ソフトウェア／制御設定の参考例を共有する


## 本リポジトリの使い方
- 各種ドキュメント(サンプルコード及び解説等)は [こちら(Document)](/Document/) を参照願います。
- 各種ファイル類のダウンロードは [こちら(Download)](/Download/) を参照願います。

## 動作環境
本リポジトリに含まれるセットアッププログラム及びサンプルコードは、  
AUTD3入門キットに含まれる機器での動作を前提に検証されています。  
他の環境での動作は保証していません
