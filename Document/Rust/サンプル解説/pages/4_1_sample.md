# 4. サンプルプログラム実行
## 4.1 サンプル一覧
キットには下記のサンプルプログラムが格納されています。

|タイトル|	ファイル名|	概要|
| --- | --- | --- |
| 単一焦点 | Sample01_single.rs | 空間の一点に触覚点を生成する |
| 複数焦点 | Sample02_multi.rs | 空間に二点の触覚点を生成する |
| 焦点移動及びON/OFF | Sample03_move.rs | 焦点を移動、及び、ON/OFFの切り替えを行う |
| ベッセルビーム | Sample04_bessel.rs | ベッセルビームによる線状に触覚点を生成する |
| STM(単焦点) | Sample05_stm.rs | STM(時空間変調)により動きのある触覚点を生成する |

※ 先頭を大文字の'S'としています。

<br>
サンプルソースはデスクトップの「RustSample」フォルダ下に格納されています。
フォルダパスは下記となります。

```
　　/home/aiplay/Desktop/RustSample
```
