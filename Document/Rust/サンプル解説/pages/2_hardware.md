# 2. ハードウェア接続
AUTD3触覚ボードキットの各機器を、下記の様に接続します。  

ADLINK社製 MXE-210の場合  
![接続図](./image/hw_connect.png)

キーボード/マウス/モニタはキットに付属しませんので別途ご用意願います。
なおPC本体の画像出力はDP(DisplayPort)となります。必要に応じてDP-HDMI変換機器等もご用意下さい。

PC本体とAUTD3ボードは、LANケーブル(カテゴリ5e以上)で接続します。
PC側はLAN1(左側)に接続し、触覚ボード側は「中央のコネクタ」に接続します。
上記画像の「EtherCAT in」に接続します）
