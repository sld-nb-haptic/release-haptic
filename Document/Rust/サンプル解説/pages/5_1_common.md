# 5. サンプルプログラム解説
## 5.1 共通部分
### AUTD3触覚ボードの基本構造
AUTD3触覚ボード内の動作概念図を下記に示します。
![ブロック](./image/autd3_diagram.png)

| ブロック | 役割 |
| --- | --- |
| Gain | 位相と振幅を生成します。 |
| STM | 時間に沿って変化する位相と振幅を生成します。 |
| Modulation | AM変調を加味します。 |
| Silencer | 消音化処理を行います。 |
| PWM | 各振動子を振動させる電気信号を生成します。 |
| Trunsducer | 電気信号を超音波に変換します。 |


位相制御にて位相と振幅を定義（触覚を発生させる位置等を決定）し、  
変調制御にてAM変調付加（触覚の感じを強くするなどの加工）を加え、  
消音機能にて可聴音の除去（耳障りなノイズを抑制）させてから、  
パルス幅変調で最終的な信号を生成し振動子（超音波スピーカー）を動作させます。  


ユーザプログラムは緑色の部分に対してそれぞれの動作設定を指示することで、
様々な触覚を生む音場を発生させることができます。

| 部分 | 指定内容 |
| --- | --- |
| Gain/STM部 | どの位置にどの様な焦点を発生させるかを指定します。 |
| Modulation部 | 触覚を決定する波を指定します。 |
| Silencer部 | 位相等が変化した場合に生じる可聴音を抑止する方法を指定します。 |

AUTD3触覚ボードを動作させるための基本的な流れは下記の様になります。  
①	デバイス構成定義  
②	通信方法決定  
③	デバイス接続  
④	消音処理定義と送信  
⑤	位相制御の定義と送信  
⑥	変調制御の定義と送信  
⑦	位置や状態の変化が生じるまで待機（変更する場合は、④⑤⑥を再度行う）  
⑧	デバイス切断  

サンプルでは主に①～③、⑤～⑥をまとめて記述する場合があります。

### 通信方法
AUTD3ライブラリでは複数の通信方法(Link)がサポートされています。

* TwinCATリンク  
　　Beckhoff社のソフトウェア製品を用いて通信を行います。（Windows専用）  
　　大量のAUTD3ボードでも遅延を最小限にした高精度の通信を行えます。  

* EtherCrabリンク  
　　Rust言語で記述されたオープンソースなライブラリを使用して通信を行います。  
　　数枚程度のAUTD3ボード環境では最も安価で安定した通信を行えます。  

* Remoteリンク  
　　リモートサーバ経由でAUTD3ボードと通信を行います。  
　　プログラムの実行環境に通信用のライブラリ(TwinCAT等)をインストールする必要がありません。  

参考：https://shinolab.github.io/autd3-doc/jp/Users_Manual/API/link.html

キットに含まれるサンプルプログラムはLink(通信手段)としてEtherCrabを使用しています。

通信を開始する際に何れかのリンクを指定する必要がありますが、  
基本的にそれ以降はリンク(通信方法)の違いを気にすることなく操作を行う事が可能です。    
（EtherCrabを用いて動作確認後にリンク部分だけをTwinCAT用に変更するだけで、  
 それ以外のコードは修正の必要がありません）

### 外部ライブラリ(クレート)の追加
各サンプルをビルドするには下記の外部ライブラリ(クレート)をプロジェクトに追加する必要があります。

|タイトル|	ファイル名|	必要外部ライブラリ |
| --- | --- | --- |
| 単一焦点 | Sample01_single.rs | autd3, autd3-link-ethercrab |
| 複数焦点 | Sample02_multi.rs | autd3, autd3-link-ethercrab, autd3-gain-holo |
| 焦点移動及びON/OFF | Sample03_move.rs | autd3, autd3-link-ethercrab |
| ベッセルビーム | Sample04_bessel.rs | autd3, autd3-link-ethercrab |
| STM(単焦点) | Sample05_stm.rs | autd3, autd3-link-ethercrab |

外部ライブラリはキットにダウンロードされており、  
オフラインでプロジェクトに追加するには「``` --offline ```」オプションを指定します。


例1) 単一焦点サンプルをビルドする場合
```
cargo add autd3 --offline
cargo add autd3-link-ethercrab --offline
```

例2) 複数焦点サンプルをビルドする場合
```
cargo add autd3 --offline
cargo add autd3-link-ethercrab --offline
cargo add autd3-gain-holo --offline
```
