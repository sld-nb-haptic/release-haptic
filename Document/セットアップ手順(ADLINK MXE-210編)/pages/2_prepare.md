# 2. 準備するもの

各作業にて必要な機器類を下記に示します。

| 作業ステップ| 必要機器類| 説明 |
| --- | --- | ---  |
| セットアップ用USB作成| ① 作業用PC(Windows10or11)<br>② OSインストール用USBメディア<br>③ 環境セットアップ用USBメディア<br>④ インターネット回線 | 作業用PCで各USBメディアを作成します。<br><br>ファイルのダウンロードにインターネット回線が必要です。 |
| ハードウェアセットアップ| ハードウェアのセットアップ作業は必要ありません。 |
| OSインストール | ① キットPC(キーボード/マウス/モニタ)<br>② OSインストール用USBメディア |  |
| サンプル環境セットアップ| ① キットPC(キーボード/マウス/モニタ)<br>② 環境セットアップ用USBメディア | キーボード/マウスはUSB<br>モニタはDP(DisplayPort)<br>HDMIモニタの場合、<br>DP→HDMI変換のコネクタ等が必要 |
| 動作確認| ① キットPC(キーボード/マウス/モニタ)<br>② AUTD3ボード<br>③ AUTD3ボード用電源(DC 24V)<br>④ AUTD3ボード接続用LANケーブル |  |
