# 3. セットアップ用USBメディア作成
## 3.1 準備等
セットアップ用USBメディア作成では、 Windows10/11がインストールされ  
インターネット経由で必要なファイルをダウンロードできる環境が必要です。

本作業で作成されるUSBメディアは、複数のキットPCセットアップで使いまわすことができます。  
ただし複数のセットアップを平行して実施する場合は、平行作業するキットPC台分のUSBメディアが必要となります。

USBメディアはFAT32またはexFATでフォーマットされた状態  
(内部データが削除された状態、かつ、フォーマット可能なことを確認できた状態)で準備してください。

セットアップ用USBメディアは下記の２つを用意します。  
| 名称| 必要容量| 用途 |
| --- | --- | ---  |
| OSインストール用USBメディア| 8GB以上| OS(Ubuntu)のインストールを行います。 |
| 環境セットアップ用USBメディア| 2GB以上| サンプル及びサンプルを動作させるための追加パッケージをインストールし、<br>デスクトップ上のアイコン等を作成します。 |
