# 4. サンプルプログラム実行
## 4.1 サンプル一覧
キットには下記のサンプルプログラムが格納されています。

|タイトル|	ファイル名|	概要|
| --- | --- | --- |
| 単一焦点 | sample01_single.py | 空間の一点に触覚点を生成する |
| 複数焦点 | sample02_multi.py | 空間に二点の触覚点を生成する |
| 焦点移動及びON/OFF | sample03_move.py | 焦点を移動、及び、ON/OFFの切り替えを行う |
| ベッセルビーム | sample04_bessel.py | ベッセルビームによる線状に触覚点を生成する |
| STM(単焦点) | sample05_stm.py | STM(時空間変調)により動きのある触覚点を生成する |
